Wybierz usługę.
Komendy Minecraft korzystają z RCON przez SSH. Włącz RCON w server.properties. Hasło RCON pozostaje na VPS. Odpowiedź „nieznana komenda” pochodzi z serwera/pluginu; komendy wpisuj jak w konsoli Minecraft, np. corestatus zamiast core status.

Edytor

Duże pliki otwierają się fragmentami po 256 kB. Zapis zmienia wyłącznie widoczny fragment i tworzy kopię całego pliku .rawcraft.bak.

Kopia obejmuje katalog serwera ustawiony w aplikacji. Dla spójnej kopii świata najpierw zatrzymaj usługę. Kopie są przechowywane na tym samym VPS — pobierz je również na komputer.

Edytor skryptów SSH

BASH · DO 128 KiB

Wklej dowolną liczbę linii (do 128 KiB), np. kilka komend z poradnika. Uruchomienie jest potwierdzane. Skrypt działa w osobnej powłoce Bash, w katalogu wybranej instancji, zatrzymuje się przy pierwszym błędzie i nie zmienia katalogu interaktywnego terminala.

0 linii · 0 B / 128 KiB

⚠ Wykonanie może zmienić lub usunąć dane na VPS. Skrypty nie obsługują interaktywnych pytań o hasło sudo; do takich komend użyj konsoli SSH powyżej.

Połączenie i tryb
Bezpieczeństwo wpłat
Core zapisuje saldo i pokwitowanie razem. Powtórzone ID zamówienia nie nalicza środków ponownie. Podczas przygotowania edycji nowe doładowania są blokowane.
Bramka PayByLink potwierdza płatność w backendzie WWW. Ten ekran pokazuje gotowość Core i mostu; nie potwierdza dostępności operatora ani dokonania wpłaty.
Klucze API pozostają na VPS. Panel nie pobiera danych kont ani historii transakcji.

 
Brak aktualnego odczytu.

 
Uprawnienia na VPS
Aplikacja korzysta z praw konta SSH. Tryb administratora wymaga root lub działającego sudo; nie zmienia uprawnień konta ani sudoers.
Sprawdzanie uprawnień…
Pliki, kopie, RCON i terminal mogą działać przez sudo. Usługi PM2 działają jako użytkownik SSH.
Zmień hasło konta VPS
Zmienia hasło konta Linux. Zmiana własnego hasła aktualizuje też zapamiętany profil aplikacji.

 
Wygląd aplikacji
Skala: wybierz Auto lub 100–200% na górnym pasku. Auto dopasowuje widok do szerokości okna, także na monitorze 4K.
Połączenie z VPS
Możesz używać wersji portable albo instalatora Windows z wyborem folderu. Aktualizacje pozostają w wybranej lokalizacji. Profil i hasło chroni Windows.
Po każdym logowaniu panel automatycznie włącza uprawnienia root przez sudo, jeśli konto ma do nich dostęp. Tryb użytkownika można wybrać dla bieżącej sesji.
